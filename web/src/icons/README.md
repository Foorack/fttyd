# Icons

Taken from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme)
(MIT, see `LICENSE` next to this file). The SVGs are unmodified except where noted; they are
bundled by Vite, so they end up inside the single binary.

| File | Used for |
| --- | --- |
| `folder-interface.svg` | the "parent directory" toolbar button |
| `folder-update.svg` | the "refresh" toolbar button |
| `folder-controller.svg` | the "show hidden files" toggle |
| `folder-include.svg` | the "new folder" action |
| `folder-upload.svg` | the "upload files" action |
| `folder-routes.svg` | the "follow the shell" toggle |
| `folder-base.svg` | a directory in the tree |
| `folder-admin.svg` | a directory that cannot be opened |
| `document.svg` | a file or symlink in the tree |

`web/public/favicon.svg` is derived from this set's `powershell.svg`: the badge is filled with a
blue-to-cyan gradient and the prompt is drawn white, where the original is one flat colour.
